# DeSSIN — The Decentralised AI Training Network

## A Guided Tour of the Protocol

This book explains how DeSSIN works, from the big idea all the way down to the fee maths. Each chapter builds on the previous one. No PhD required — if you can read Python and have a rough idea of what a blockchain is, you are ready.
